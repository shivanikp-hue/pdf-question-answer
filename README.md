# 📄 PDF Question Answering System (LLM)

## 🔹 Description
This project allows users to upload a PDF and ask questions based on its content using a Large Language Model (LLM).

## 🔹 Features
- Extract text from PDF
- Split into chunks
- Store using FAISS vector database
- Semantic search
- Generate answers using LLM

## 🔹 Tech Stack
- Python
- LangChain
- FAISS
- Hugging Face Transformers

## 🔹 How to Run

```bash
pip install -r requirements.txt
python app.py
